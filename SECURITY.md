# Security

If you find a way to make Claim SOL build, co-sign or credit a transaction it should not,
please tell us privately before publishing it.

**Contact:** Telegram [@SimuZT](https://t.me/SimuZT)

Please include the steps to reproduce and, if possible, a transaction signature or a
simulation. We answer every report.

Things we especially want to hear about:

- any transaction built by the server that moves something other than rent back to the
  owner and our visible fee;
- any way to get the project wallet to sign a message it did not build;
- any way to get referral credit or points without a real, confirmed claim.
